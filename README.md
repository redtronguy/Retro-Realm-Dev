# Retro Realm

A single-player pixel-art action RPG: *Skyrim* meets *Fable*, based on the project's novel
*The Tidebound Count* (`book/`). Open world, moral choices, several endings. Steam Deck first.
The engine is being chosen (see decisions, Q12). (Multiplayer is shelved for now.)

- Agents (Claude, Codex): start with [`AGENTS.md`](AGENTS.md).
- Decisions and open questions: [`.collab/decisions.md`](.collab/decisions.md)
- Work items: [`.collab/tasks/`](.collab/tasks/)
- `prototype/c/`: early C prototype of the abandoned city-builder (kept for history only).
