# Retro Realm

A single-player SNES-style game: SimCity 2000 city-building meets Skyrim-style adventure.
Build the town by day, defend it by night. Targets Steam Deck, Raspberry Pi, iPhone and ESP32,
all built in the cloud through CI. (Multiplayer is shelved for now.)

- Agents (Claude, Codex): start with [`AGENTS.md`](AGENTS.md).
- Decisions and open questions: [`.collab/decisions.md`](.collab/decisions.md)
- Work items: [`.collab/tasks/`](.collab/tasks/)
- `prototype/c/`: early C prototype of the game rules (reference only; the real game is Rust).
