# The Tidebound Count: Branches

What happens if Edric chooses differently. Each event below branches from the canon novel at a decision point; each file names the exact moment, links back to the canon path, and plays out every other option, with a **Later** section showing how the choice comes back.

Each option is marked with its effect on the two dials from the game design:
- **Heart**: + is mercy, − is vengeance.
- **Tide**: + is taking or keeping the sea god's power, − is giving it back.

Branches are independent "what ifs": each one assumes canon everywhere except its own choice.

Endings: the canon ending is [Chapter 31](../31-wait-and-hope.md). Codex's *The Sea That Keeps* is in [alternate-endings](../alternate-endings/README.md). The rest are in Act V below.
